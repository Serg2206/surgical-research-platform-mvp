### Очерк 1: "Сравнение двух хирургических техник: от идеи до публикации"

### Введение: Рождение исследовательского вопроса

Вы освоили новую технику минимально инвазивной резекции печени и заметили, что пациенты восстанавливаются быстрее, чем при традиционном открытом доступе. Коллеги скептичны: "Это субъективное впечатление". Как превратить наблюдение в доказательство?

### Шаг 1: Формулировка исследовательского вопроса (PICO)

P (Population) — Пациенты с единичными метастазами колоректального рака в печени

I (Intervention) — Лапароскопическая резекция печени

C (Comparator) — Открытая резекция печени

O (Outcome) — Первичный: длительность госпитализации; Вторичные: кровопотеря, осложнения, время операции

### Шаг 2: Выбор дизайна исследования

### Вариант А: Ретроспективное когортное исследование

Преимущества: Быстро, дешево, данные уже собраны

Недостатки: Высокий риск систематических ошибок, нет контроля за распределением пациентов

### Вариант Б: Проспективное РКИ

Преимущества: Минимальные систематические ошибки, золотой стандарт

Недостатки: Долго, дорого, сложная логистика

### Вариант В: Проспективное когортное с пропенсити-матчингом

Преимущества: Баланс между надежностью и реализуемостью

Недостатки: Требует статистической экспертизы

Ваш выбор: Начнем с ретроспективного анализа (доказательство концепции), затем проспективное РКИ.

### Шаг 3: Расчет размера выборки

### Исходные данные из литературы:

Средняя длительность госпитализации при открытой резекции: 8 дней (SD = 3)

Клинически значимое сокращение: 2 дня (25%)

α = 0.05, мощность = 80%

Расчет (используя онлайн-калькулятор или формулу):

n = 2 × (Zα/2 + Zβ)² × σ² / δ²

где:

- Zα/2 = 1.96 (для α = 0.05)

- Zβ = 0.84 (для мощности 80%)

- σ = 3 (стандартное отклонение)

- δ = 2 (ожидаемая разница)

n = 2 × (1.96 + 0.84)² × 9 / 4

n = 2 × 7.84 × 2.25

n ≈ 36 пациентов на группу

С учетом 15% потерь: 36 / 0.85 ≈ 43 пациента на группу (86 всего)

### Очерк 2: "Факторы риска послеоперационных осложнений: логистическая регрессия в действии"

### Введение: От наблюдения к прогнозированию

В вашей практике накопились данные о 200 панкреатодуоденальных резекциях. Вы заметили, что у одних пациентов восстановление проходит гладко, у других развиваются тяжелые осложнения. Можно ли предсказать риск заранее? Какие факторы наиболее важны?

### Зачем нужна логистическая регрессия?

Простое сравнение (χ² тест) показывает связь одного фактора с исходом:

Диабет: осложнения 45% vs нет диабета 25% (p=0.01)

Проблема: Пациенты с диабетом часто старше, имеют ожирение, сопутствующую патологию. Что на самом деле влияет?

Логистическая регрессия позволяет:

Оценить независимое влияние каждого фактора

Контролировать эффект конфаундеров

Построить модель предсказания риска

### Шаг 1: Определение исходов и предикторов

### Исход (зависимая переменная):

Тяжелые осложнения (Clavien-Dindo ≥III): да/нет

Бинарная переменная — подходит для логистической регрессии

Предоперационные:

Интраоперационные:

### Шаг 2: Первичный анализ — одно факторный анализ

# Одно факторный логистический регрессионный анализ

library(dplyr)

# Функция для одно факторного анализа

univariate_analysis <- function(data, outcome, predictor) {

formula <- as.formula(paste(outcome, "~", predictor))

model <- glm(formula, data = data, family = binomial)

# Получение результатов

or <- exp(coef(model)[2])

ci <- exp(confint(model)[2,])

p <- summary(model)$coefficients[2,4]

return(c(OR = or, CI_lower = ci[1], CI_upper = ci[2], p_value = p))

}

# Применение к каждому предиктору

predictors <- c("age", "sex", "BMI_cat", "ASA", "diabetes",

"bilirubin", "preop_drainage", "op_time",

"blood_loss", "transfusion", "pancreas_texture",

"duct_diameter")

results <- sapply(predictors, function(x)

univariate_analysis(data, "severe_complication", x))

### Шаг 6: Клиническое применение — калькулятор риска

**Уравнение логистической регрессии:**

```

log(odds) = β₀ + β₁×ASA + β₂×Transfusion + β₃×Soft_pancreas + β₄×Narrow_duct

где:

β₀ = -2.87 (константа)

β₁ = 0.65 (ASA III-IV)

β₂ = 0.82 (Гемотрансфузия)

β₃ = 1.24 (Мягкая текстура)

β₄ = 1.14 (Проток <3 мм)

Вероятность = e^(log(odds)) / (1 + e^(log(odds)))

```

**Пример расчета:**

Пациент:

- ASA III (да = 1)

- Интраоперационная гемотрансфузия (да = 1)

- Мягкая поджелудочная железа (да = 1)

- Диаметр протока 2 мм (да = 1)

```

log(odds) = -2.87 + 0.65×1 + 0.82×1 + 1.24×1 + 1.14×1

= -2.87 + 3.85

= 0.98

Вероятность = e^0.98 / (1 + e^0.98)

= 2.66 / 3.66

= 0.727 (72.7%)

```

**Интерпретация**: У этого пациента прогнозируемый риск тяжелых осложнений 73%.

**Клиническое применение**:

- Информирование пациента

- Решение о профилактических мерах (антибиотики, соматостатин)

- Интенсивность послеоперационного мониторинга

### Очерк 3: "Анализ выживаемости в онкохирургии: кривые Каплана-Мейера и регрессия Кокса"

### Введение: Особенности онкологических данных

В отличие от исходов типа "есть/нет", в онкохирургии нас интересует время до события: рецидива, метастазирования, смерти. Традиционные методы (t-тест, логистическая регрессия) не подходят по двум причинам:

Цензурирование — не все пациенты достигли события к концу наблюдения

Время — ключевая переменная — важно не только ЧТО произошло, но и КОГДА

| 36 | 84 | 4 | 12 | 74.2% |

### Очерк 4: "Размер имеет значение: расчет мощности исследования и размера выборки"

### Введение: Трагедия недостаточно мощных исследований

Реальный сценарий: Хирург провел РКИ, сравнивая две техники герниопластики (n=30 на группу). Результат: частота рецидивов 10% vs 15% (p=0.52). Вывод публикации: "Различий не обнаружено, техники эквивалентны".

Проблема: Исследование не имело достаточной мощности для выявления этого различия. Отсутствие статистической значимости ≠ отсутствие клинического различия!

### Ключевые концепции

Ошибка I рода (α, альфа):

Ложноположительный результат

Заключить, что различие есть, когда его нет

Обычно устанавливается на уровне 0.05 (5%)

Ошибка II рода (β, бета):

Ложноотрицательный результат

Заключить, что различия нет, когда оно есть

Обычно устанавливается на уровне 0.20 (20%)

Мощность (Power) = 1 - β:

Вероятность обнаружить различие, если оно существует

Обычно требуется ≥80% (0.80)

Золотой стандарт: 90%

Клинически значимое различие (Effect size):

Минимальное различие, которое имеет клиническое значение

Определяется ДО начала исследования на основе клинического суждения

### Сценарий 1: Сравнение двух пропорций (бинарный исход)

Исследование: РКИ по сравнению лапароскопической vs открытой холецистэктомии

Первичный исход: Раневая инфекция (да/нет)

Планирование:

Шаг 1: Определите базовую частоту (p₁)

Из литературы: раневая инфекция при открытой холецистэктомии ≈ 8%

p₁ = 0.08

Шаг 2: Определите клинически значимое снижение

Эксперты согласились: снижение до 3% клинически важно

p₂ = 0.03

Абсолютное снижение: δ = p₁ - p₂ = 0.05 (5%)

Шаг 3: Установите α и мощность

α = 0.05 (двусторонний тест)

Мощность = 0.80 (80%)

Шаг 4: Расчет размера выборки

Формула (упрощенная):

n = [Z_(α/2)√(2p̄(1-p̄)) + Z_β√(p₁(1-p₁) + p₂(1-p₂))]² / (p₁ - p₂)²

где:

Z_(α/2) = 1.96 (для α=0.05, двусторонний)

Z_β = 0.84 (для мощности 80%)

p̄ = (p₁ + p₂)/2 = 0.055

Расчет с помощью R:

sig.level = 0.05,

power = 0.80,

alternative = "two.sided")

#               h = 0.213

Ожидаемое выбывание: 10%

Скорректированный размер: 346 / 0.90 = 385 на группу (770 всего)

### Сценарий 2: Сравнение двух средних (непрерывный исход)

Исследование: Сравнение послеоперационной боли (VAS, 0-10) между двумя анальгетическими режимами

Планирование:

Шаг 1: Определите параметры контрольной группы

Из предыдущих данных: μ₁ = 5.2, σ = 1.8

Шаг 2: Определите клинически значимое различие

### Сценарий 4: Пост-хок анализ мощности (когда уже поздно...)

Ситуация: Исследование завершено, различие незначимо (p=0.18). Рецензент требует "оценить мощность".

Ваше исследование:

Сравнение двух групп по длительности госпитализации

n=40 на группу

Группа А: M=6.8 дня, SD=2.1

Группа Б: M=7.5 дня, SD=2.3

Разница: 0.7 дня, p=0.18

Расчет мощности пост-хок:

# Effect size из данных

pooled_sd <- sqrt(((40-1)*2.1^2 + (40-1)*2.3^2) / (40+40-2))

# pooled_sd = 2.2

d <- 0.7 / 2.2

# d = 0.32

# Мощность при обнаружении этого эффекта

pwr.t.test(n = 40,

d = 0.32,

sig.level = 0.05,

type = "two.sample")$power

# Мощность = 0.35 (35%)

Интерпретация: Исследование имело только 35% шанс обнаружить наблюдаемое различие. Это недостаточно мощное исследование.

Правильный ответ рецензенту:

"Ретроспективный расчет мощности показал, что при наблюдаемом effect size (d=0.32) исследование имело мощность 35%. ### Сценарий 5: Многоцентровое исследование — коррекция на центры

Проблема: Различия между центрами могут увеличить вариабельность.

Решение: Увеличить размер выборки на коэффициент инфляции дизайна (Design Effect, DE).

Формула: DE = 1 + (m - 1) × ICC

где:

m = среднее число пациентов на центр

ICC = внутриклассовый коэффициент корреляции (обычно 0.01-0.05)

Пример:

Одноцентровый расчет: 200 пациентов

Планируется 10 центров (m=20 пациентов/центр)

ICC = 0.02 (из предыдущих исследований)

DE = 1 + (20 - 1) × 0.02 = 1.38

Скорректированный размер: 200 × 1.38 = 276 пациентов
