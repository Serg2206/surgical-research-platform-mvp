# Интраоперационная навигация, ICG-флуоресценция, 3D-печать

## Цели лекции

## Введение. Видеть то, что не видит глаз

Хирургия — визуальная дисциплина, но глаз не видит микроциркуляцию, перфузию на уровне капилляров, желчный проток, скрытый в инфильтрате. Технологии усиления зрения — ICG-флуоресценция, интраоперационное УЗИ, навигация — не заменяют глаз, а расширяют его.

## 1. ICG-флуоресценция

### 1.1. Принцип

Индоцианин зелёный вводится в/в, флуоресцирует при освещении ближним инфракрасным светом (NIR, 780–820 нм), визуализируется NIR-камерой. T½ 3–5 мин. Доза: 2,5–5 мг для перфузии, 0,05 мг/кг для холангиографии.

### 1.2. Применения

| Применение | Доказательная база |
|---|---|
| Оценка перфузии анастомоза | 8 RCT (2022–2025): ↓ несостоятельность на 30–50 % |
| Идентификация желчных протоков | 5 RCT: ↓ повреждение ОЖП при холецистэктомии |
| Оценка жизнеспособности кишки | Сопоставимо с Doppler, лучше «на глаз» |
| Идентификация мочеточников | Case series |

### 1.3. Оценка перфузии анастомоза

ICG 2,5–5 мг болюс → NIR-визуализация через 30–60 сек. Критерии: яркая однородная флуоресценция — хорошая перфузия; тусклая/пятнистая — недостаточная; отсутствие — ишемия. Данные: несостоятельность 3–5 % (ICG-группа) vs. 8–12 % (контроль); в 10–20 % случаев ICG показывает недостаточную перфузию → хирург меняет линию резекции.

### 1.4. Идентификация желчных протоков

ICG 2,5 мг в/в за 45 мин до холецистэктомии (или 0,05 мг/кг за 2–4 ч) → экскреция с желчью → флуоресценция протоков во время диссекции треугольника Кало. Визуализация протоков 90–95 %; при выраженном воспалении/ожирении затруднена.

### 1.5. Оценка жизнеспособности кишки

Перфузия > 80 % от нормы — жизнеспособна; 50–80 % — пограничная (повторная оценка); < 50 % — нежизнеспособна → резекция. Применение: мезентериальная ишемия (second-look), странгуляционная непроходимость, оценка культи/анастомоза.

## 2. Интраоперационная навигация

**Интраоперационное УЗИ (IOUS):** печень (сосуды, опухоли, абсцессы), желчные протоки (холедохолитиаз при невозможности ERCP), поджелудочная, сосуды (Doppler), абсцессы, расширенный FAST при травме. Преимущества: реальное время, без излучения. Ограничения: оператор-зависимость.

**Интраоперационная флюороскопия:** холангиография, контроль SEMS, контроль дренажей, ангиография в гибридной операционной.

**Интраоперационная КТ (iCT):** ограниченная доступность (гибридные операционные, экспертные центры); контроль сложных резекций, навигация при дренировании.

**Навигация на основе предоперационной КТ:** 3D-реконструкция + наложение на интраоперационное изображение (AR); в экстренной хирургии — ограниченно (нет времени на планирование); перспектива — AI-автоматическая сегментация ускорит применение.

## 3. 3D-печать и дополненная реальность

**3D-печать:** анатомические модели для планирования сложных плановых операций; в экстренной хирургии практически не применима (нет времени на моделирование), кроме предоперационного планирования отсроченных реконструкций (planned ventral hernia).

**AR (дополненная реальность):** наложение 3D-реконструкции на интраоперационное изображение для идентификации сосудов/протоков/опухоли; статус 2026 — ранняя клиническая практика (пилотные проекты); ограничения — точность регистрации, время подготовки, стоимость.

**AI-ассистированная навигация:** computer vision распознаёт анатомические структуры (желчный проток, сосуды, мочеточник) в реальном времени, предупреждает о близости инструмента; статус 2026 — ранняя клиническая практика (Theator, Safe Surgery AI, Proximie); не замена хирурга.

## 4. Алгоритм интеграции

**Минимальный набор (каждый стационар):** лапароскопическая видеосистема Full HD/4K, ICG-флуоресценция (NIR-камера), интраоперационное УЗИ, интраоперационная холангиография.

**Расширенный набор (экспертные центры):** роботическая платформа + ICG, гибридная операционная, AR-навигация, AI computer vision, 3D-реконструкция.

**Рекомендации:** ICG-флуоресценция — при каждом колоректальном анастомозе (WSES/EAES 2024); IOUS — при холецистэктомии с неясной анатомией, резекции печени, поиске абсцесса; холангиография — при подозрении на холедохолитиаз; AR/AI — по доступности, в экспертных центрах.

## Клинический кейс

Мужчина, 62 года, экстренная лапароскопическая резекция сигмы по поводу перфоративного дивертикулита (Hinchey III), Hartmann. День 3: re-laparoscopy для формирования отсроченного анастомоза (стабильная физиология).

**Операция:** ревизия — культя сигмы жизнеспособна, перитонит регрессирует; формирование колоректального анастомоза (механический шов); **ICG-флуоресценция**: проксимальный край — яркая перфузия (90 %); дистальный край (культя прямой кишки) — тусклая, неоднородная (55 %) → решение: мобилизация дополнительного сегмента (селезёночный изгиб) → повторный анастомоз с лучшим кровоснабжением → повторная ICG: перфузия 85 % → приемлемо; превентивная илеостомия добавлена как дополнительная защита.

**Без ICG:** анастомоз с перфузией 55 % → риск несостоятельности 15–25 % → вероятная re-laparotomy на 5–7-е сутки. **С ICG:** изменение линии резекции → несостоятельность 3–5 %; одна операция вместо двух.

## Заключение. Семь принципов

1. ICG-флуоресценция — стандарт 2026 при колоректальном анастомозе: снижение несостоятельности на 30–50 %.
2. ICG для идентификации протоков при холецистэктомии — особенно при воспалении/ожирении.
3. IOUS — доступный универсальный инструмент.
4. 3D-печать и AR — перспектива, не стандарт; в экстренной хирургии — ограниченно.
5. AI computer vision — ранняя практика; предупреждение о риске, не замена хирурга.
6. Минимальный набор: Full HD лапароскоп + ICG + IOUS + холангиография.
7. Технология усиливает, но не заменяет клиническое мышление.
