# Интервенционная радиология как партнёр хирурга

**Курс:** Абдоминальная неотложная хирургия — 2026 · **Модуль 9.** Минимально инвазивные технологии в экстренной хирургии · **Лекция 9.3**
**Хронометраж:** 35 минут · **Аудитория:** хирурги, интервенционные радиологи, анестезиологи, ординаторы

## Цели лекции

- Систематизировать методы IR в экстренной абдоминальной хирургии (дренирование, эмболизация, стентирование).
- Определить показания к IR как альтернативе или дополнению к операции.
- Сформулировать алгоритм: хирургия vs. IR vs. комбинированный подход.
- Обосновать роль IR в step-up approach при панкреатите, source control при перитоните, гемостазе при ЖКК.
- Определить организацию взаимодействия хирург–радиолог (MDT, гибридная операционная).

## Введение. Хирургия без разреза

Интервенционная радиология — не конкурент хирурга, а продолжение его рук там, где скальпель не нужен, опасен или недостаточен. В 2026 году 30–40 % экстренных абдоминальных вмешательств включают IR-компонент.

## 1. Методы IR

| Метод | Показания | Навигация |
|---|---|---|
| Чрескожное дренирование | Абсцессы, инфицированный некроз, желчные протоки (PTBD) | КТ/УС |
| Ангиография + эмболизация | ЖКК, травма, псевдоаневризма | Флюороскопия/DSA |
| Стентирование | Обтурация (SEMS), холедох, мочеточник | Флюороскопия/ЭУС |
| TIPS | Портальная гипертензия, кровотечение из ВРВ | Флюороскопия |
| EUS-guided drainage | Панкреатические скопления, абсцессы | ЭУС |

### 1.1. Чрескожное дренирование

Показания: абсцесс > 3 см доступный, аппендикулярный абсцесс > 5 см, дивертикулярный абсцесс Hinchey II, печёночный абсцесс, инфицированный некроз поджелудочной. Техника: КТ-навигация, катетер 8–14 Fr (pigtail), посев, промывание. Технический успех 90–95 %, клинический 80–90 %, осложнения 5–10 %. При неэффективности (48–72 ч) — операция.

### 1.2. Ангиография и эмболизация

Показания: ЖКК при неудаче эндоскопии, посттравматическое кровотечение при NOM, послеоперационное кровотечение, псевдоаневризма. Технический успех 90–95 %, клинический 85–95 %, рецидив 10–20 %, ишемия 5–10 % (ниже при суперселективной), летальность < 1 %.

### 1.3. Стентирование

SEMS — bridge-to-surgery/bridge-to-chemotherapy при обтурации КРР (успех 90–95 % технический, противопоказан при перфорации). Билиарный стент — при холангите (ERCP+стент, PTBD+стент при неудаче ERCP). Мочеточниковый стент — при обструкции.

## 2. Алгоритм: хирургия vs. IR vs. комбинация

Перфорация/некроз/деструкция органа → хирургия. Абсцесс > 3 см доступный → IR-дренирование + АБТ (неэффективность 72 ч → хирургия). ЖКК, неудача эндоскопии → ангиография+эмболизация (неэффективность → хирургия). Обтурация КРР → SEMS bridge-to-surgery (неэффективность/противопоказания → хирургия). Холангит → ERCP+сфинктеротомия/стент (неэффективность → PTBD → хирургия). Инфицированный некроз поджелудочной → step-up (АБТ → IR-дренирование → VARD → открытая некрэктомия). Травма, стабильный → NOM ± эмболизация (нестабильный → хирургия).

### 2.1. Гибридная операционная

Операционная с ангиографом/КТ/УЗИ для одномоментного хирургического и IR-вмешательства: лапароскопическая холецистэктомия + интраоперационная холангиография + ERCP (rendezvous); лапаротомия + интраоперационная ангиография+эмболизация; резекция кишки + IR-дренирование абсцесса; TIPS + лапароскопическая ревизия. Преимущества: одномоментность, снижение числа повторных вмешательств, мультидисциплинарность.

## 3. IR в контексте конкретных нозологий

**Перитонит и source control:** локализованный абсцесс → IR-дренирование, не операция; генерализованный перитонит → операция (IR не заменяет source control); послеоперационный абсцесс → IR первая линия. **Острый панкреатит (step-up):** ANC/WON → чрескожное/EUS-дренирование → неэффективность → VARD/эндоскопическая некрэктомия → крайняя мера — открытая. **ЖКК:** верхнее — ЭГДС→IR-эмболизация→хирургия; нижнее — колоноскопия→КТ-ангиография→IR-эмболизация→хирургия. **Травма:** NOM+эмболизация при active extravasation — успех NOM возрастает с 70 % до 90–95 %. **Обтурация КРР:** SEMS→операция при неэффективности.

## 4. Организация взаимодействия

**MDT:** хирург (source control, резекция), интервенционный радиолог (дренирование, эмболизация, стентирование), эндоскопист (ЭГДС, колоноскопия, ERCP, SEMS), анестезиолог, онколог/химиотерапевт, реаниматолог. **Протокол:** доступность IR 24/7 (или в течение 60 мин), чёткие показания (протоколы: абсцесс > 3 см → IR; ЖКК, неудача ЭГДС → IR), совместный обход, аудит исходов.

## Клинический кейс

Мужчина, 55 лет, 5 дней назад — лапароскопическая резекция сигмы (Hartmann) по поводу перфоративного дивертикулита. День 5: лихорадка 39,5 °C, боль в левом фланге. КТ: межпетлевой абсцесс 7×5 см в зоне культи, без генерализованного перитонита.

**Диагноз:** послеоперационный абсцесс, без перитонита. **Тактика:** IR-дренирование (КТ-навигация, катетер 12 Fr, аспирация 40 мл гноя, посев, промывание); АБТ меропенем эмпирически → по посеву (E. coli ESBL + Enterococcus) — коррекция; день 2 CRP 280→150, T 38,2 °C, отделяемое серозное; день 5 CRP 45, T 37,0 °C, контрольная КТ — абсцесс уменьшился до 1,5 см; удаление дренажа; день 7 CRP 12, выписка на пероральную АБТ. При неэффективности IR — re-laparotomy, ревизия культи (несостоятельность?), разобщение при необходимости.

## Заключение. Семь принципов

1. IR — партнёр хирурга: 30–40 % экстренных вмешательств включают IR-компонент.
2. Абсцесс > 3 см доступный → IR-дренирование, не операция при стабильности.
3. ЖКК, неудача эндоскопии → IR-эмболизация (успех 85–95 %).
4. Step-up при панкреатите: АБТ → IR → VARD → открытая (крайняя мера).
5. SEMS при обтурации КРР: bridge-to-surgery, не при перфорации.
6. Неэффективность IR (72 ч) → операция, не ждать бесконечно.
7. MDT + гибридная операционная — оптимальная организация.
