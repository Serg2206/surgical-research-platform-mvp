# Острый панкреатит: хирургический тайминг

**Курс:** Абдоминальная неотложная хирургия — 2026 · **Модуль 5.** Острые заболевания гепатопанкреатобилиарной зоны · **Лекция 5.3**
**Хронометраж:** 35 минут · **Аудитория:** хирурги, панкреатологи, анестезиологи-реаниматологи, интервенционные радиологи

## Цели лекции

- Классифицировать острый панкреатит по Revised Atlanta Classification 2012 (обновление WSES 2024).
- Обосновать step-up approach при инфицированном некрозе.
- Определить хирургический тайминг: когда НЕ оперировать и когда оперировать.
- Сравнить методы некрэктомии: VARD, синус-тракт, открытая, лапароскопическая.
- Сформулировать алгоритм ведения билиарного панкреатита.

## Введение. Хирург, который не оперирует

При остром панкреатите лучшее хирургическое решение зачастую — НЕ оперировать. Данные RCT однозначны: ранняя открытая некрэктомия (первые 2 недели) ассоциирована с летальностью 40–60 %, консервативное ведение + отсроченный step-up approach — с летальностью 15–25 %. Разница — в тайминге и подходе.

## 1. Классификация

### 1.1. По морфологии

Интерстициальный отёчный панкреатит (диффузное увеличение, однородное усиление, без некроза) vs. некротический (некроз паренхимы и/или перипанкреатической клетчатки, non-enhancing зоны > 30 %).

### 1.2. По тяжести

| Тяжесть | Определение | Летальность |
|---|---|---|
| Лёгкий | Без органной недостаточности, без локальных осложнений | < 1 % |
| Среднетяжёлый | Транзиторная органная недостаточность (< 48 ч) и/или локальные осложнения | 3–5 % |
| Тяжёлый | Персистирующая органная недостаточность (> 48 ч) | 20–40 % |

### 1.3. Локальные осложнения (по времени)

Острое перипанкреатическое скопление (APFC, < 4 нед) → псевдокиста (> 4 нед); острое некротическое скопление (ANC, < 4 нед) → walled-off necrosis (WON, > 4 нед). Дренирование/некрэктомия показаны при WON (сформирована капсула), не при ANC (если нет инфицирования с сепсисом).

## 2. Диагностика

Амилаза/липаза > 3× верхней границы нормы; CRP > 150 мг/л через 48 ч → некротический панкреатит; PCT > 0,5 → подозрение на инфицированный некроз; АЛТ > 150 → билиарная этиология (PPV 95 %). КТ с в/в контрастом оптимально через 72–96 ч (раньше некроз может быть не виден); CTSI (Balthazar) ≥ 7 → тяжёлый некротический панкреатит. Прогностические шкалы: Ranson, APACHE II, BISAP, Modified Marshall.

## 3. Лечение: консервативная фаза (0–2 недели)

**Принцип: не оперировать.** Инфузия — агрессивная goal-directed в первые 12–24 ч; обезболивание — мультимодальная аналгезия; нутриция — раннее энтеральное питание (24–48 ч), парентеральное только при невозможности энтерального; АБТ — НЕ рутинно, только при подтверждённой/предполагаемой инфекции; профилактика ВТЭО.

**Билиарный панкреатит:** АЛТ > 150 → билиарная этиология. ERCP при холангите — экстренно (< 24 ч); при персистирующей обструкции — срочно (24–72 ч); без холангита и обструкции — ERCP не показана экстренно. Холецистэктомия: при лёгком билиарном панкреатите — LC в течение той же госпитализации; при тяжёлом/некротическом — отсроченная (через 6–8 недель).

## 4. Хирургическое лечение: step-up approach

### 4.1. Показания к вмешательству

Абсолютные: инфицированный некроз с сепсисом, не отвечающий на АБТ; перфорация полого органа; кровотечение (псевдоаневризма — ангиоэмболизация/операция); компартмент-синдром. Относительные: персистирующий WON с симптомами > 4 недель.

### 4.2. Правило 4 недель

WSES 2024: вмешательство откладывается до 4 недель (пока это возможно) — до этого срока некроз не отграничен (ANC, без капсулы), операция в ранней фазе даёт массивное кровотечение и высокую летальность; после 4 недель формируется WON с капсулой — вмешательство безопаснее. Исключение: септический шок, не отвечающий на АБТ и минимальное дренирование → вмешательство раньше 4 недель (damage control).

### 4.3. Step-up approach (PANTER trial)

Шаг 1: АБТ (7–14 дней) → нет ответа (48–72 ч) → Шаг 2: чрескожное/эндоскопическое (EUS-guided, LAMS) дренирование → нет ответа (50–70 % случаев) → Шаг 3: минимально инвазивная некрэктомия (VARD, синус-тракт, эндоскопическая) → нет ответа → Шаг 4: открытая некрэктомия (крайняя мера, летальность 20–40 %).

### 4.4. Методы некрэктомии

| Метод | Летальность | Примечание |
|---|---|---|
| VARD | 15–25 % | Ретроперитонеальный, видеоассистированный, через канал дренажа |
| Синус-тракт | 15–25 % | Повторные сеансы каждые 48–72 ч |
| Эндоскопическая (LAMS) | 10–20 % | TENSION trial: сопоставима с VARD, меньше грыж/свищей |
| Открытая | 20–40 % | Крайняя мера |

## 5. АБТ при инфицированном некрозе

Эмпирически меропенем (проникает в некроз) или пип/тазо; целенаправленно по FNA/посеву при дренировании; 14–21 день по динамике; антифунгальные при Candida в посевах.

## Клинический кейс

Мужчина, 52 года, интенсивная опоясывающая боль 24 ч, рвота, алкогольный анамнез. АД 110/70, ЧСС 105, T 38,2 °C. Амилаза 1250, липаза 2800, WBC 16, CRP 180, АЛТ 45 (не билиарный), Ca²⁺ 2,0. КТ (72 ч): некротический панкреатит, non-enhancing > 50 %, CTSI 8.

**Диагноз:** острый некротический панкреатит, тяжёлый, алкогольная этиология. **Тактика:** неделя 1–2 — консервативно (агрессивная инфузия, эпидуральная аналгезия, раннее энтеральное питание через назоинтестинальный зонд, без АБТ — нет инфицирования); неделя 2 — лихорадка 39,2 °C, PCT 4,5, газ в некрозе на КТ (pathognomonic инфицированного некроза) → меропенем, FNA (E. coli+Klebsiella); неделя 3 — сепсис персистирует, < 4 недель (ANC) → чрескожное дренирование, посев + Candida → добавлен микафунгин; неделя 5 (> 4 нед, WON сформирован) — VARD, повторный VARD через 72 ч; неделя 7 — CRP 15, дренажи удалены, выписка.

## Заключение. Восемь принципов

1. Ранняя операция при панкреатите = вред; не оперировать в первые 2 недели (кроме абсолютных показаний).
2. Step-up approach — стандарт: АБТ → дренирование → минимально инвазивная некрэктомия → открытая (крайняя мера).
3. Правило 4 недель: вмешательство при WON, не при ANC (исключение — рефрактерный сепсис).
4. Раннее энтеральное питание (24–48 ч), не парентеральное «на всякий случай».
5. АБТ — не рутинно, только при инфицировании.
6. Билиарный панкреатит: ERCP при холангите (< 24 ч); LC в ту же госпитализацию при лёгком.
7. КТ через 72–96 ч, раньше некроз не виден.
8. VARD/эндоскопическая некрэктомия предпочтительнее открытой.
