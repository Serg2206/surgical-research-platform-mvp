# Обтурационная непроходимость: опухоли, желчные камни, инородные тела

**Курс:** Абдоминальная неотложная хирургия — 2026 · **Модуль 3.** Острая кишечная непроходимость · **Лекция 3.4**
**Хронометраж:** 35 минут · **Аудитория:** хирурги, онкохирурги, ординаторы, эндоскописты, интервенционные радиологи

## Цели лекции

- Классифицировать обтурационную непроходимость по этиологии.
- Обосновать роль SEMS как bridge-to-surgery при опухолевой обтурации.
- Определить тактику при экстренной опухолевой непроходимости: стентирование vs. операция vs. стома.
- Диагностировать и лечить желчнокаменную непроходимость (синдром Бувре).
- Сформулировать онкохирургический подход к экстренной обтурации.

## Введение. Когда непроходимость — это онкология

Обтурационная непроходимость опухолевого генеза — пересечение неотложной хирургии и онкохирургии. Экстренная операция при колоректальном раке — компромисс онкологической радикальности: нет полноценного стадирования, нет предоперационной подготовки. Стент — мост к плановой операции, не лечение. Задача — найти баланс между экстренностью и онкологической адекватностью.

| Причина | Доля |

| Опухоли тонкой кишки | 5–10 % |

## 2. Опухолевая толстокишечная непроходимость

10–30 % пациентов с КРР поступают с картиной острой непроходимости; левые отделы — 70 % обтурационных форм. Летальность при экстренной операции 10–20 % (vs. 2–5 % при плановой), частота стомы 40–60 % (vs. 10–15 %).

### 2.1. Стадирование в экстренных условиях

Доступно: КТ грудь/живот/таз, CEA, интраоперационная биопсия. Недоступно: полная колоноскопия, МРТ малого таза, ПЭТ-КТ, предоперационная биопсия при полной обтурации.

### 2.2. Алгоритм тактики

Резектабельная, без перфорации/перитонита: **SEMS** (bridge-to-surgery, 2–4 недели → стадирование → плановая операция; успех 90–95 % технический, 80–90 % клинический; осложнения — перфорация 3–5 %, миграция 10–15 %; противопоказания — перфорация, перитонит, опухоль < 5 см от ануса) или, при неэффективности/противопоказаниях, **операция** (резекция + primary anastomosis ± diverting ileostomy, или Hartmann при нестабильности); при нерезектабельной опухоли — паллиативная стома или SEMS. С перфорацией/перитонитом → экстренная операция (Hartmann + лаваж + дренирование), НЕ стентирование. Правые отделы — правосторонняя гемиколэктомия + primary anastomosis.

### 2.3. SEMS: bridge-to-surgery

Показания (ESGE/WSES 2024): левосторонняя обтурация КРР, резектабельная опухоль, без перфорации/перитонита. Противопоказания: перфорация/перитонит, опухоль < 5 см от ануса, нерезектабельная опухоль (SEMS как паллиация — отдельное решение), извитость/множественные стенозы. Результаты: технический успех 90–95 %, клинический 80–90 %, перфорация 3–5 %, миграция 10–15 %; снижение частоты стомы (15 % vs. 50 % при экстренной операции); онкологические исходы сопоставимы с экстренной операцией.

### 2.4. Онкологическая адекватность в экстренных условиях

Обязательно даже экстренно: R0-резекция, мезоколон-эксцизия (CME) при правосторонней резекции, TME при раке прямой кишки при возможности, лимфаденэктомия ≥ 12 лимфоузлов, оценка перитонеума/печени/яичников, маркировка опухоли. Допустимо отложить: полную колоноскопию, МРТ малого таза, решение о неоадъювантной терапии.

### 2.5. Перфорация опухоли

Онкологическая катастрофа: перитонеальная диссеминация + контаминация + сепсис. Тактика — экстренная резекция (Hartmann) + лаваж + АБТ, НЕ стентирование. Прогноз хуже, чем при непроходимости без перфорации.

## 3. Желчнокаменная непроходимость (синдром Бувре)

Желчный камень (> 2,5 см) → холецисто-дуоденальный/кишечный свищ → миграция в просвет → обтурация (обычно терминальная подвздошная кишка). **Триада Риглера:** пневмобилия, тонкокишечная непроходимость, эктопический желчный камень (sensitivity 90–95 %). Тактика: экстренная энтеротомия проксимальнее обтурации, извлечение камня, поперечное ушивание, ревизия на второй камень; при некрозе — резекция; холецистэктомию в экстренных условиях НЕ выполняем (высокий риск осложнений) — планово через 6–8 недель.

## 4. Инородные тела и безоары

Инородные тела прямой кишки — трансанальное извлечение; тонкая кишка — энтеротомия; при перфорации — резекция. Безоары (фитобезоары после гастрэктомии, трихобезоары, фармакобезоары) — эндоскопическая фрагментация или энтеротомия/резекция при тонкокишечной обтурации. Инвагинация у взрослых в 70–90 % случаев имеет lead point (опухоль) → тактика — резекция, не деторсия.

## Клинический кейс

Мужчина, 67 лет, нарастающее вздутие, запор 5 дней, потеря массы 8 кг за 3 месяца. АД 125/80, пальпируется малоподвижное образование 6×4 см в левой подвздошной области. WBC 12, CEA 48. КТ: циркулярная опухоль сигмы 5 см, полная обтурация, дилатация ободочной до 9 см (слепая — 11 см), илеоцекальный клапан компетентен, без перфорации, без метастазов, 2 увеличенных периколических ЛУ.

**Диагноз:** КРР сигмы, обтурационная непроходимость, cT3N?M0, без перфорации.

**Тактика (предпочтительно):** SEMS → декомпрессия → 2–3 недели стадирования (колоноскопия с биопсией, МРТ, ПЭТ-КТ, CEA) → гистология (умереннодифференцированная аденокарцинома) → плановая лапароскопическая резекция сигмы + CME + первичный анастомоз без стомы → адъювантная ХТ по стадированию. При неэффективности SEMS — экстренная резекция + primary anastomosis + diverting ileostomy или Hartmann; при перфорации/перитоните — экстренный Hartmann без стентирования.

## Заключение. Семь принципов

1. Опухолевая непроходимость — онкохирургическая проблема в экстренной упаковке.
2. SEMS — bridge-to-surgery, а не лечение.
3. Перфорация = абсолютное противопоказание к SEMS.
4. R0 + лимфаденэктомия ≥ 12 узлов — обязательны даже экстренно.
5. Желчнокаменная непроходимость: энтеротомия, не холецистэктомия экстренно.
6. Инвагинация у взрослых = резекция (риск malignancy), не деторсия.
7. Стадирование — после разрешения непроходимости, адъювантная терапия — по результатам.
