# Диагностика и дифференциация острой кишечной непроходимости

**Курс:** Абдоминальная неотложная хирургия — 2026 · **Модуль 3.** Острая кишечная непроходимость · **Лекция 3.1**
**Хронометраж:** 35 минут · **Аудитория:** хирурги, ординаторы, радиологи, анестезиологи

## Цели лекции

- Классифицировать острую кишечную непроходимость (ОКН) по механизму, уровню и степени.
- Провести дифференциальную диагностику механической и паралитической непроходимости.
- Идентифицировать КТ-семиотику strangulation и closed-loop obstruction.
- Сформулировать алгоритм диагностики от приёмного покоя до верификации диагноза.
- Определить маркеры странгуляции, требующие экстренной операции.

## Введение. Непроходимость — это не диагноз, а симптом

ОКН составляет 12–18 % всех экстренных хирургических заболеваний брюшной полости. Летальность при неосложнённой спаечной непроходимости — 3–5 %, при странгуляционной с некрозом — 25–40 %, при мезентериальной ишемии с тотальным некрозом — 60–80 %. Разница определяется временем: временем от начала симптомов до диагноза, от диагноза до операции, от начала ишемии до резекции.

## 1. Классификация

### 1.1. По механизму

| Тип | Механизм | Доля |
|---|---|---|
| Механическая | Физическое препятствие просвету или брыжейке | 85–90 % |
| Динамическая (паралитическая) | Нарушение моторики без механического препятствия | 10–15 % |
| Смешанная | Сочетание | Редко |

### 1.2. По уровню

Тонкокишечная высокая (ДПК, тощая) — ранняя рвота желчью; тонкокишечная низкая (подвздошная) — рвота с задержкой, разлитое вздутие; толстокишечная (сигма, ободочная, слепая) — поздняя рвота, выраженное вздутие, асимметрия живота.

### 1.3. По степени

Частичная (субкомпенсированная), полная (декомпенсированная), странгуляционная (сдавление брыжейки → ишемия → некроз).

### 1.4. По этиологии

| Причина | Доля |
|---|---|
| Спаечная | 60–70 % |
| Опухолевая | 15–20 % |
| Грыжевая (ущемлённая) | 8–12 % |
| Странгуляционная (заворот, узлообразование) | 3–5 % |
| Обтурационная (желчные камни, инородные тела) | 2–4 % |
| Воспалительная (Крон, дивертикулит) | 3–5 % |
| Прочие (инвагинация, радиационный энтерит) | 1–3 % |

## 2. Клиническая картина и дифференциальная диагностика

### 2.1. Классическая тетрада

Боль (схваткообразная при механической, постоянная при паралитической/странгуляционной), рвота (ранняя при высокой, поздняя при низкой), вздутие (локальное или разлитое), задержка стула и газов.

### 2.2. Механическая vs. паралитическая

| Признак | Механическая | Паралитическая |
|---|---|---|
| Боль | Схваткообразная | Постоянная, тупая |
| Рвота | Ранняя, многократная | Поздняя/отсутствует |
| Перистальтика | Усилена, «шум плеска» | Ослаблена/отсутствует |
| КТ | Transition zone, whirl sign, closed loop | Диффузная дилатация без transition zone |
| Причина | Спайки, опухоль, грыжа, заворот | Перитонит, послеоперационный парез, электролиты |

## 3. КТ-семиотика: gold standard визуализации

КТ с в/в контрастом (sensitivity 90–95 %, specificity 90–96 %) подтверждает/исключает механическую непроходимость, определяет уровень (transition zone) и причину, выявляет признаки странгуляции, оценивает жизнеспособность кишки, исключает closed loop.

| КТ-признак | Значение | Тактика |
|---|---|---|
| Transition zone | Место обструкции | Подтверждает механическую непроходимость |
| Whirl sign | Заворот, closed loop | Экстренная операция |
| Closed loop | Замкнутая петля с конвергирующими сосудами | Экстренная операция |
| Lack of wall enhancement | Ишемия/некроз стенки | Экстренная операция |
| Pneumatosis intestinalis | Некроз стенки | Экстренная операция |
| Portal venous gas | Тяжёлая ишемия/некроз | Экстренная операция |

## 4. Признаки странгуляции и алгоритм диагностики

**КТ-признаки:** closed loop, whirl sign, lack of enhancement, отёк брыжейки, геморрагическая свободная жидкость, pneumatosis, утолщение стенки > 3 мм с нарушением слоистости.

**Клинические маркеры:** постоянная боль, тахикардия > 100, лейкоцитоз > 15×10⁹/л, нарастающий лактат > 2 ммоль/л, перитонеальные знаки, лихорадка > 38,5 °C, кровь в стуле. **Правило:** ≥ 2 маркеров странгуляции → экстренная операция, не наблюдение.

**Алгоритм:** клиническая оценка (тетрада, грыжевые ворота — обязательно) → лабораторно (лактат, электролиты, коагулограмма) → визуализация (обзорная рентгенография как скрининг, КТ в течение 60 мин как верификация) → дифференциация → решение (странгуляция/перитонит → экстренная операция; полная механическая без странгуляции → консервативно 24–72 ч → операция при неэффективности; частичная → консервативно + наблюдение; паралитическая → лечение причины).

**Роль Gastrografin challenge** при спаечной непроходимости без странгуляции: 100 мл водорастворимого контраста, рентген через 4–24 ч — контраст в толстой кишке → разрешение (PPV 90–95 %); не достиг за 24 ч → высокая вероятность операции.

## 5. Дифференциальная диагностика

Паралитический илеус (анамнез операции/перитонита, диффузная дилатация без transition zone); острый панкреатит (амилаза/липаза резко повышены); мезентериальная ишемия без обструкции (боль «не по статусу», мягкий живот); псевдообструкция Огилви (дилатация ободочной без механической причины); токсический мегаколон (диарея, «гармошка» на КТ); гинекологическая патология (УЗИ, β-ХГЧ).

## Клинический кейс

Женщина, 72 года, через 18 ч от начала: схваткообразная боль, многократная рвота, вздутие, задержка стула и газов. В анамнезе — экстирпация матки 3 года назад, аппендэктомия 10 лет назад. АД 110/70, ЧСС 98, усиленная перистальтика с металлическим оттенком. WBC 13,5, CRP 85, лактат 2,4, K⁺ 3,2. КТ: дилатация тощей/подвздошной кишки до 4 см, transition zone, whirl sign, closed loop (U-образная петля 12 см), снижение enhancement стенки, свободная жидкость в малом тазу.

**Диагноз:** спаечная тонкокишечная непроходимость, странгуляционная. **Тактика:** экстренная операция (не консервативно, не Gastrografin) — лапароскопическая ревизия → адгезиолизис, расправление closed loop, оценка жизнеспособности (розовая/перистальтирует/кровоточит — сохранение; тусклая — резекция), анастомоз или стома по стабильности, лаваж, дренирование.

## Заключение. Шесть принципов диагностики ОКН

1. ОКН — симптом, а не диагноз: найдите причину.
2. КТ с в/в контрастом — gold standard, обзорная рентгенография — скрининг.
3. Transition zone + whirl sign + closed loop = странгуляция до доказательства обратного.
4. Механическая ≠ паралитическая — тактика принципиально различается.
5. Gastrografin challenge — при спаечной без странгуляции, не при closed loop.
6. Осматривайте грыжевые ворота у каждого пациента — самая частая пропущенная причина.
