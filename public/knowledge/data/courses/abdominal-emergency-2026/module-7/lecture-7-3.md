# Острые осложнения после плановых онкоопераций

**Курс:** Абдоминальная неотложная хирургия — 2026 · **Модуль 7.** Экстренная абдоминальная онкохирургия · **Лекция 7.3**
**Хронометраж:** 35 минут · **Аудитория:** онкохирурги, хирурги, анестезиологи-реаниматологи, ординаторы

## Цели лекции

- Идентифицировать наиболее частые острые осложнения после плановых онкоопераций на ЖКТ.
- Диагностировать несостоятельность анастомоза: клиника, КТ-семиотика, тайминг.
- Сформулировать алгоритм re-intervention: консервативно → IR → re-laparotomy.
- Определить тактику при послеоперационном кровотечении, перитоните, кишечной непроходимости.
- Обосновать принципы damage control в контексте послеоперационных осложнений у онкопациентов.

## Введение. Когда плановая операция становится экстренной

В 10–20 % случаев плановая онкооперация превращается в экстренную ситуацию: несостоятельность анастомоза, кровотечение, перитонит, непроходимость — у пациента, который одновременно онкологический (иммуносупрессия, кахексия, предшествующая ХТ) и хирургический (осложнение, требующее re-intervention).

## 1. Несостоятельность анастомоза

### 1.1. Эпидемиология и факторы риска

| Операция | Частота несостоятельности | Летальность при несостоятельности |
|---|---|---|
| Колоректальная (передняя резекция) | 5–15 % | 10–20 % |
| Гастрэктомия | 2–5 % | 20–40 % |
| Панкреатодуоденальная резекция | 5–15 % | 10–30 % |
| Эзофагэктомия | 10–20 % | 20–40 % |

Факторы риска: предоперационная ХТ/ХЛТ, гипоальбуминемия (< 30 г/л), курение, диабет, ожирение, низкий колоректальный анастомоз (< 5 см от ануса).

### 1.2. Клиника и диагностика

Тайминг: 5–7-е сутки (диапазон 3–14). Лихорадка > 38,5 °C после 4-х суток, тахикардия, боль, мутное/каловое отделяемое по дренажу, при тазовом анастомозе — боль в промежности; при ретроперитонеальном — сепсис без перитонеальных знаков. КТ с ректальным/пероральным контрастом (sensitivity 85–95 %): свободная жидкость, экстравазация, абсцесс.

### 1.3. Алгоритм лечения

Локальный абсцесс без перитонита → IR-дренирование + АБТ + НГЗ/парентеральное питание → контроль КТ 48–72 ч → при неэффективности re-laparotomy. Перитонит/шок → экстренная re-laparotomy (< 6 ч) → разобщение анастомоза, стома, лаваж, дренирование, НЕ повторный анастомоз, при шоке — DCS + open abdomen. Субклиническая утечка → наблюдение + АБТ + НГЗ + контроль КТ.

## 2. Послеоперационное кровотечение

Раннее (< 24 ч, техническое — лигатура/клипса/шов) → re-laparotomy. Позднее (24 ч–14 дней, эрозия сосуда/некроз/инфекция) → IR-эмболизация или re-laparotomy. Из анастомоза (5–10-е сутки) → эндоскопический гемостаз при доступности. Алгоритм: стабильный + Hb > 70 → наблюдение+трансфузия+коррекция коагулопатии; нестабильный/Hb < 70/> 4 ед. ЭМ → КТ-ангиография → эмболизация; рефрактерный шок → re-laparotomy + DCS при коагулопатии.

## 3. Послеоперационная кишечная непроходимость

Ранняя (< 30 дней): паралитический илеус (2–5-е сутки, консервативно), ранняя спаечная непроходимость (7–14-е сутки, консервативно 72 ч → операция), внутренняя грыжа (после гастрэктомии по Ру, правосторонней гемиколэктомии — экстренная операция), заворот. Поздняя (> 30 дней): стандартный алгоритм спаечной ОКН, рецидив опухоли (стадирование → SEMS/операция), лучевой энтерит/стриктура.

## 4. Другие осложнения

Послеоперационный панкреатит (после ПДР/гастрэктомии) — консервативно, при инфицированном некрозе — step-up. Хилусный асцит (после D2-лимфаденэктомии) — диета MCT, октреотид, при неэффективности IR/операция. Тромбоэмболия — высокий риск у онкопациентов, расширенная профилактика НМГ 28 дней после абдоминальной онкооперации (WSES/ASCO 2024). Раневые осложнения (ИОХВ 5–15 %) — вскрытие, дренирование, АБТ при целлюлите/сепсисе.

## Клинический кейс

Мужчина, 66 лет, 7 дней назад — лапароскопическая передняя резекция прямой кишки (pT3N1, R0, TME, primary anastomosis на 4 см от ануса, превентивная илеостомия), предоперационная ХЛТ. День 7: лихорадка 39,2 °C, боль в малом тазу, мутное отделяемое по тазовому дренажу. АД 105/70, ЧСС 108, перитонеальные знаки локально. WBC 18, CRP 285, PCT 6,5, лактат 2,8. КТ (с ректальным контрастом): экстравазация в зоне анастомоза, тазовый абсцесс 5×4 см, минимальный пневмоперитонеум.

**Диагноз:** несостоятельность колоректального анастомоза (день 7), тазовый абсцесс, локальный перитонит, после ХЛТ. **Тактика (предпочтительно при стабильности):** IR-дренирование абсцесса + меропенем + НГЗ/парентеральное питание; превентивная илеостомия уже защищает анастомоз → заживление; контроль КТ 48–72 ч → удаление дренажа → АБТ 7–10 дней; ректоскопия через 4 недели; закрытие илеостомы через 3 месяца. При перитоните/шоке — экстренная re-laparotomy → разобщение анастомоза → Hartmann, НЕ повторный анастомоз. Несостоятельность не отменяет адъювантную ХТ (FOLFOX/CAPOX) — начинается после заживления.

## Заключение. Семь принципов

1. Несостоятельность анастомоза — 5–15 % после колоректальной операции; подозревайте при лихорадке > 38,5 °C после 4-х суток + рост CRP.
2. КТ с ректальным/пероральным контрастом — gold standard диагностики.
3. Локальный абсцесс → IR-дренирование + АБТ, не re-laparotomy при стабильности.
4. Перитонит/шок → экстренная re-laparotomy, разобщение + стома, НЕ повторный анастомоз.
5. Превентивная илеостомия при низком колоректальном анастомозе снижает тяжесть несостоятельности.
6. Расширенная профилактика ВТЭО — 28 дней после абдоминальной онкооперации.
7. Несостоятельность ≠ отмена адъювантной ХТ — продолжить после заживления по MDT.
