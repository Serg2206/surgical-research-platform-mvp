# Перфорация и кровотечение при опухолях ЖКТ

**Курс:** Абдоминальная неотложная хирургия — 2026 · **Модуль 7.** Экстренная абдоминальная онкохирургия · **Лекция 7.2**
**Хронометраж:** 35 минут · **Аудитория:** онкохирурги, хирурги, эндоскописты, интервенционные радиологи, ординаторы

## Цели лекции

- Классифицировать перфорации и кровотечения при опухолях ЖКТ по локализации и механизму.
- Определить онкохирургический подход к перфорации опухоли желудка, тонкой и толстой кишки.
- Сформулировать алгоритм при кровоточащей опухоли: эндоскопия → IR → хирургия.
- Обосновать объём экстренной резекции с онкологической адекватностью.
- Определить роль паллиативной хирургии при нерезектабельных опухолях.

## Введение. Когда опухоль прорывается или кровоточит

Перфорация опухоли — двойная катастрофа: инфекция + онкологическая диссеминация. Кровотечение из опухоли — хроническая кровопотеря, переходящая в острую; опухолевая ткань не сокращается и не тромбируется, эндоскопический и IR-гемостаз временны, резекция — единственное радикальное решение.

## 1. Перфорация опухолей ЖКТ

### 1.1. Эпидемиология и механизмы

| Локализация | Частота перфорации |
|---|---|
| Желудок | 2–5 % рака желудка |
| Толстая кишка | 3–10 % КРР |
| Тонкая кишка (GIST, лимфома) | 5–10 % |

Механизмы: перфорация опухоли (прорастание+некроз, T4b, диссеминация), перфорация проксимальнее обструкции (замкнутый контур), перфорация на фоне ХТ/лучевой терапии (некроз при быстром ответе — лимфома, GIST на иматинибе), ятрогенная (3–5 % при SEMS).

### 1.2. Тактика по локализации

Желудок — резекция (субтотальная/тотальная гастрэктомия) + D2-лимфаденэктомия при возможности; при нерезектабельности — ушивание + биопсия + паллиативная стома. Толстая кишка (левые) — Hartmann при перитоните/шоке или резекция + primary anastomosis ± ileostomy при стабильности, R0 + ≥ 12 ЛУ. Тонкая кишка (GIST) — сегментарная резекция без лимфаденэктомии (гематогенное метастазирование), R0, иматиниб после. Тонкая кишка (лимфома) — сегментарная резекция + биопсия ЛУ, ХТ после.

### 1.3. Перфорация на фоне системной терапии

Бевацизумаб — риск перфорации 1–2 %, противопоказание к продолжению. Иматиниб (GIST) — перфорация при быстром некрозе (первые 2–4 недели). Тактика: экстренная операция + отмена системной терапии + MDT.

## 2. Кровотечение при опухолях ЖКТ

### 2.1. Эпидемиология

Желудок — 10–20 % рака желудка, хроническое → острое. Толстая кишка — 5–15 % КРР, чаще хроническое (анемия). Тонкая кишка (GIST) — 20–30 %, острое массивное (богатая васкуляризация).

### 2.2. Алгоритм

Ресусцитация (restrictive Hb 70–80) → эндоскопия (временный гемостаз, успех 60–80 % — ниже, чем при язве, опухолевая ткань не сокращается, рецидив 30–50 %) → при неудаче — КТ-ангиография → эмболизация (успех 80–90 %, временный, рецидив 20–30 %) → хирургия при рецидиве/массивном кровотечении (резекция опухоли — радикальная при резектабельности, паллиативная при нерезектабельности) → системная терапия после стабилизации.

### 2.3. Особенности по локализации

Желудок — ЭГДС + гемостаз, при рецидиве резекция (субтотальная/тотальная гастрэктомия + D2), системная терапия после. GIST тонкой кишки — эндоскопия часто неэффективна (подслизистая локализация), резекция сегментарная R0 без лимфаденэктомии, иматиниб после (при KIT/PDGFRA мутации); при нерезектабельной — иматиниб → уменьшение → резекция. Колоректальный рак — хроническое кровотечение чаще, плановая колоноскопия → резекция; острое массивное редко.

### 2.4. Паллиативная хирургия при кровотечении

При нерезектабельной опухоли с рецидивирующим кровотечением: паллиативная резекция (даже без R0), повторная эмболизация, гемостатическая лучевая терапия, системная терапия (снижение размера → снижение кровотечения), поддерживающая терапия.

## Клинический кейс

Женщина, 58 лет, мелена 5 дней, Hb 65, потеря массы 4 кг за месяц. ЭГДС: экзофитная опухоль тела желудка 5 см с изъязвлением, активное подтекание → гемостаз (инъекция+коагуляция+клипсы); биопсия — низкодифференцированная аденокарцинома, диффузный тип, HER2-негативная. КТ: cT3, 4 увеличенных ЛУ, без метастазов.

**Диагноз:** рак желудка cT3N+M0, кровотечение остановлено эндоскопически. **Тактика:** ОРИТ (трансфузия Hb 65→82, ИПП); контрольная ЭГДС 24 ч — стабильно; стадирование (ПЭТ-КТ, diagnostic laparoscopy — перитонеум чист, цитология отрицательная); MDT: резектабельна → субтотальная гастрэктомия + D2 (28 ЛУ, R0, pT3N2) → периоперационная ХТ (FLOT) по MDT.

## Заключение. Семь принципов

1. Перфорация опухоли = экстренная операция: source control + онкоадекватность (R0, ≥ 12 ЛУ).
2. Кровотечение из опухоли: эндоскопия → IR → хирургия; эндоскопический гемостаз временный (рецидив 30–50 %).
3. Резекция — единственное радикальное решение при кровоточащей опухоли.
4. GIST: сегментарная резекция без лимфаденэктомии, иматиниб после.
5. Перфорация на фоне ХТ/таргетной терапии: отмена препарата + операция + MDT.
6. Паллиативная резекция допустима при нерезектабельной опухоли с рецидивирующим кровотечением.
7. MDT после стабилизации определяет адъювантную/паллиативную терапию.
