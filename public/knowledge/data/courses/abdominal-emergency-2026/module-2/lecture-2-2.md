# Хирургическая тактика: source control

**Курс:** Абдоминальная неотложная хирургия — 2026 · **Модуль 2.** Перитонит и интраабдоминальный сепсис · **Лекция 2.2**
**Хронометраж:** 35 минут · **Аудитория:** хирурги, ординаторы, интервенционные радиологи, анестезиологи

## Цели лекции

- Сформулировать принципы source control при интраабдоминальной инфекции (WSES 2024).
- Определить показания к оперативному vs. интервенционному (IR) source control.
- Обосновать выбор объёма операции: локальная резекция vs. расширенная резекция vs. лаваж.
- Сравнить лапароскопический и открытый подход при перитоните.
- Определить показания и тайминг re-look / planned re-laparotomy.

## Введение. Source control — краеугольный камень

Без адекватного source control ни один антибиотик не спасёт пациента с перитонитом: антибиотики не проникают в некротические ткани, не закрывают перфорацию, не удаляют гной. По данным WSES 2024, неадекватный source control — независимый предиктор летальности при интраабдоминальном сепсисе (OR 3,2; 95% CI 2,1–4,8), важнее тяжести сепсиса, возраста и коморбидности.

## 1. Принципы source control

Source control — совокупность мероприятий: устранение источника (резекция, ушивание, удаление); контроль контаминации (лаваж ≥ 3–5 л при локальном, ≥ 10 л при генерализованном; аспирация); дренирование (активные дренажи в зонах скопления, IR-дренирование абсцессов); разобщение/восстановление (анастомоз при благоприятных условиях или стома).

**Тайминг:** экстренный (< 6 ч) при генерализованном перитоните и шоке; срочный (< 24 ч) при локализованном перитоните с нарастающей динамикой, абсцессе > 5 см; отсроченный (24–72 ч) при абсцессе < 5 см (АБТ → IR → операция при неэффективности). Правило WSES 2024: при септическом шоке source control должен быть выполнен в течение 6 часов — каждый час задержки увеличивает летальность на 7–8 %.

## 2. Оперативный vs. интервенционный source control

**Когда оперируем:** перфорация полого органа с перитонитом, некроз кишки, деструктивный аппендицит/холецистит с перитонитом, генерализованный перитонит, несостоятельность анастомоза с перитонитом.

**Когда дренируем (IR):** абсцесс > 3 см доступный; периаппендикулярный абсцесс > 5 см (+ interval appendectomy через 6–8 недель); печёночный абсцесс; послеоперационный локализованный абсцесс; инфицированный некроз поджелудочной (step-up).

## 3. Объём операции

### 3.1. Принцип «минимально достаточного объёма»

Удалить источник, контролировать контаминацию, не наносить избыточную травму: перфоративная язва ДПК → ушивание + Graham patch, не резекция желудка; деструктивный аппендицит → аппендэктомия + лаваж, не гемиколэктомия; перфорация дивертикула сигмы → резекция сигмы, не субтотальная колэктомия (если нет тотального поражения).

### 3.2. Анастомоз vs. стома

| Фактор | В пользу анастомоза | В пользу стомы |
|---|---|---|
| Гемодинамика | Стабильная | Шок, вазопрессоры |
| Перитонит | Локальный/отсутствует | Генерализованный, фекальный |
| Питание | Нормальное | Гипоальбуминемия (< 25 г/л) |
| Ткани | Жизнеспособные | Отёк, ишемия |
| Лактат/pH | Норма | Ацидоз, лактат > 4 |

WSES 2024: при генерализованном перитоните и шоке — Hartmann; при локализованном процессе и стабильной физиологии — primary anastomosis ± diverting ileostomy.

### 3.3. Лаваж

Локальный перитонит 2–3 л тёплого NaCl 0,9 %; генерализованный — 5–10 л до «чистых вод». Антисептики (повидон-йод, хлоргексидин) в брюшную полость не рекомендованы (цитотоксичность). Антибиотики в лаваж не рекомендованы.

## 4. Лапароскопический vs. открытый подход

Лапароскопический source control (EAES/WSES 2024) показан при локализованном и распространённом перитоните при стабильной гемодинамике, IAP ≤ 12 мм рт. ст.: меньшая травма, лучшая визуализация, ниже частота раневых инфекций и грыж. Открытый — при генерализованном перитоните с шоком (DCS), рефрактерной нестабильности, массивной дилатации, потребности в open abdomen. Конверсия — при невозможности идентификации источника, неконтролируемом кровотечении, нарастающей нестабильности.

## 5. Re-look и planned re-laparotomy

**Показания:** мезентериальная ишемия с резекцией (24–48 ч, mandatory); DCS/open abdomen (24–72 ч, planned); нестабильный гемостаз (12–24 ч); негативная динамика после source control (24–48 ч). Стабильная динамика после адекватного source control — re-look не показан.

**Критерии адекватности source control за 24–48 ч:** лактат снижается, CRP/PCT снижаются, гемодинамика стабилизируется, диурез восстанавливается, перитонеальные знаки регрессируют. Отсутствие положительной динамики → подозрение на неадекватный source control → re-look.

## Клинический кейс

Женщина, 71 год. 5 дней назад — плановая резекция сигмы по поводу рака. На 5-е сутки — нарастание боли, лихорадка 39,5 °C, АД 85/55 (норадреналин), ЧСС 130, GCS 13. По дренажу — мутное отделяемое с кишечным содержимым. WBC 22, CRP 410, PCT 18, лактат 5,4, pH 7,22, креатинин 195. КТ: несостоятельность колоректального анастомоза, свободная жидкость с включениями, пневмоперитонеум.

**Диагноз:** несостоятельность анастомоза, фекальный перитонит, септический шок. Healthcare-associated. Severe.

**Тактика:** экстренная re-laparotomy (< 2 ч) — разобщение анастомоза, концевая колостомия + закрытие культи прямой кишки (Hartmann), лаваж 10 л, дренирование, open abdomen при нестабильности; АБТ меропенем + ванкомицин; посевы; ОРИТ; re-look через 48 ч.

## Заключение. Семь принципов source control

1. Source control первичен — без него антибиотики бессильны.
2. Тайминг решает: при шоке < 6 ч, каждый час задержки = +7–8 % летальности.
3. Минимально достаточный объём — не больше и не меньше, чем нужно.
4. Анастомоз vs. стома — решение по физиологии: шок + перитонит = стома.
5. IR-дренирование — партнёр хирурга: абсцесс > 3 см доступный → дренируем.
6. Re-look — запланированный этап при мезентериальной ишемии, DCS.
7. Критерии адекватности динамические: лактат, CRP, гемодинамика, а не «визуально всё хорошо».
