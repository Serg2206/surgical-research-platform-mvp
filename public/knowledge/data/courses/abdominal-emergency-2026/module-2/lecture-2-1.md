# Классификация и стратификация перитонита

**Курс:** Абдоминальная неотложная хирургия — 2026 · **Модуль 2.** Перитонит и интраабдоминальный сепсис · **Лекция 2.1**
**Хронометраж:** 35 минут · **Аудитория:** хирурги, ординаторы, анестезиологи-реаниматологи

## Цели лекции

- Классифицировать перитонит по этиологии, распространённости и условиям возникновения в рамках WSES/SIS-E 2024.
- Стратифицировать тяжесть перитонита с использованием Mannheim Peritonitis Index, qSOFA, SOFA и динамических биомаркеров.
- Определить микробиологический профиль community-acquired и healthcare-associated перитонита.
- Сформулировать prognostic assessment для выбора тактики (source control, АБТ, ОРИТ).
- Разграничить первичный, вторичный и третичный перитонит по клинико-лабораторным критериям.

## Введение. Перитонит — не диагноз, а процесс

Перитонит при перфоративном аппендиците у 25-летнего мужчины и перитонит при несостоятельности анастомоза после расширенной гастрэктомии у 74-летнего пациента с диабетом и ХСН — это две разные вселенные с точки зрения микробиологии, прогноза, тактики и исхода. Правильная классификация определяет правильную тактику, а правильная тактика определяет выживание.

## 1. Этиологическая классификация WSES/SIS-E 2024

### 1.1. Первичный (спонтанный) перитонит

Инфекция брюшины без идентифицируемого источника нарушения целостности ЖКТ: спонтанный бактериальный перитонит (СБП) при циррозе с асцитом, перитонит при перитонеальном диализе, редко — гематогенная диссеминация. Микробиология монобактериальная (E. coli, Klebsiella, Streptococcus pneumoniae). Тактика консервативная (антибиотики ± альбумин при СБП). Критично: перед лечением СБП исключить вторичный перитонит (КТ, анализ асцитической жидкости — полимикробная флора, билирубин/амилаза/ЩФ в асците указывают на вторичный источник).

### 1.2. Вторичный перитонит

Инфекция вследствие нарушения целостности полого/паренхиматозного органа.

| Причина | Доля |
|---|---|
| Перфоративный/деструктивный аппендицит | 25–30 % |
| Перфорация язвы желудка/ДПК | 15–20 % |
| Дивертикулит с перфорацией | 12–15 % |
| Послеоперационная несостоятельность анастомоза | 10–15 % |
| Странгуляционная непроходимость с некрозом | 8–10 % |
| Перфорация опухоли | 5–8 % |
| Травма | 5–7 % |
| Прочие (холецистит, панкреатит, гинекология) | 5–10 % |

Микробиология полимикробная: грамотрицательные (E. coli, Klebsiella, Proteus, Pseudomonas) + анаэробы (Bacteroides fragilis, Clostridium) + энтерококки. Тактика: source control (операция/IR-дренирование) + АБТ.

### 1.3. Третичный перитонит

Персистирующая или рецидивирующая инфекция после адекватного первичного source control. Критерии WSES 2024: персистенция > 48 ч после адекватного source control; положительные посевы после 48 ч АБТ; рецидив абсцесса после улучшения; исключён альтернативный источник. Микробиология смещена: ESBL, CRE, Pseudomonas, VRE, Candida. Летальность 40–60 %.

## 2. Классификация по условиям возникновения

**Community-acquired** — из дома, без госпитализации в течение 90 дней; «классическая» микробиология (E. coli, Klebsiella, Bacteroides, Enterococcus), низкая резистентность (ESBL < 10 %); эмпирическая АБТ — цефалоспорины III + метронидазол или пиперациллин/тазобактам.

**Healthcare-associated** — послеоперационный перитонит, госпитализация > 5 дней в течение 90 дней, предшествующая АБТ, катетеры/дренажи/стомы; резистентные штаммы (ESBL, Pseudomonas, MRSA, VRE, Candida); эмпирическая АБТ — карбапенемы ± ванкомицин ± антифунгальные.

## 3. Классификация по распространённости

| Степень | Определение | Пример |
|---|---|---|
| Локализованный | 1–2 анатомические зоны | Периаппендикулярный абсцесс |
| Распространённый (диффузный) | ≥ 2 зоны, не вся брюшина | Разлитой перитонит при деструктивном аппендиците |
| Генерализованный (разлитой) | Тотальное поражение брюшины | Фекальный перитонит при перфорации сигмы |

## 4. Стратификация тяжести

### 4.1. Mannheim Peritonitis Index (MPI)

Возраст > 50 (+5), женский пол (+5), органная недостаточность (+7), злокачественное новообразование (+4), длительность перитонита > 24 ч (+4), неаппендикулярный источник (+4), диффузный перитонит (+3), гнойный экссудат (+6), фекальный экссудат (+12). MPI < 21 — летальность < 10 %; 21–29 — 20–40 %; > 29 — > 50 %.

### 4.2. qSOFA и SOFA

qSOFA (скрининг у постели): ЧДД ≥ 22, систолическое АД ≤ 100, GCS < 15. qSOFA ≥ 2 → углублённая оценка (SOFA, лактат). SOFA оценивает дыхание, коагуляцию, печень, сердечно-сосудистую систему, ЦНС, почки; SOFA ≥ 2 → сепсис (Sepsis-3, подтверждено WSES 2024).

### 4.3. Динамические биомаркеры

Лактат (гипоперфузия, контроль каждые 6 ч), CRP (динамика каждые 12–24 ч), PCT (деэскалация при < 0,5), IL-6/Presepsin (опережают CRP на 6–12 ч). Динамика важнее однократного значения.

### 4.4. Интегральная стратификация WSES 2024

| Степень | Критерии | Тактика |
|---|---|---|
| Mild | Локализованный, qSOFA 0, SOFA 0–1, MPI < 21 | Source control + АБТ 4–5 дней |
| Moderate | Распространённый, qSOFA 1, SOFA 2–3, MPI 21–29 | Экстренный source control + расширенная АБТ + мониторинг |
| Severe | Генерализованный, qSOFA ≥ 2, SOFA ≥ 4, MPI > 29, шок | DCS + open abdomen + ОРИТ + prolonged АБТ |

## 5. Микробиологический профиль

**Community-acquired:** E. coli (35–45 %), Klebsiella (10–15 %), Bacteroides fragilis (20–30 %), Enterococcus faecalis (10–15 %), Streptococcus spp. (5–10 %), Clostridium spp. (5–8 %).

**Healthcare-associated:** ESBL E. coli/Klebsiella (25–35 %), Pseudomonas aeruginosa (15–20 %), VRE (10–15 %), MRSA (5–10 %), Candida spp. (10–15 %), CRE (5–10 %).

Принципы диагностики: посевы из операционного поля до начала АБТ, минимум 2 пробы из разных зон, аэробы + анаэробы (+ грибы при healthcare-associated), обязательная антибиотикограмма, повторные посевы при re-look/третичном перитоните.

## Клинический кейс

Мужчина, 58 лет, через 30 ч от начала заболевания. Дивертикулёз сигмы, диабет 2 типа (HbA1c 8,2 %), ожирение (BMI 34). АД 105/70, ЧСС 108, T 39,2 °C. Живот вздут, перитонеальные знаки в 2 зонах. WBC 19, CRP 285, PCT 6,2, лактат 3,1, креатинин 125, билирубин 28. КТ: перфорация дивертикула сигмы, периколический абсцесс 6 см, свободная жидкость в левом фланге и малом тазу, без генерализованного пневмоперитонеума.

**Стратификация:** вторичный перитонит, community-acquired, распространённый (2 зоны), qSOFA 0, SOFA 1, MPI 22 → Moderate.

**Тактика:** экстренный source control — лапароскопическая ревизия → резекция сигмы (Hartmann) + лаваж + дренирование; АБТ пиперациллин/тазобактам эмпирически; посевы аэробы+анаэробы; мониторинг лактат/6 ч, CRP/12 ч, PCT/24 ч; при негативной динамике — re-look через 24–48 ч.

## Заключение. Шесть принципов классификации

1. Перитонит — не одна болезнь: первичный, вторичный, третичный — три разные сущности с разной тактикой.
2. Community-acquired ≠ Healthcare-associated: микробиология и эмпирическая АБТ принципиально различаются.
3. Стратификация определяет тактику: mild → локальный source control, severe → DCS + ОРИТ.
4. MPI + qSOFA + лактат — минимальный набор для стратификации у постели.
5. Посевы до антибиотиков — всегда, из операционного поля, аэробы + анаэробы.
6. Динамика важнее однократного значения.
