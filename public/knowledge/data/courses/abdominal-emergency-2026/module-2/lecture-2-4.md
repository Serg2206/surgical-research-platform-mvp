# Третичный перитонит и абдоминальный сепсис в ОРИТ

**Курс:** Абдоминальная неотложная хирургия — 2026 · **Модуль 2.** Перитонит и интраабдоминальный сепсис · **Лекция 2.4**
**Хронометраж:** 35 минут · **Аудитория:** хирурги, анестезиологи-реаниматологи, хирурги ОРИТ, ординаторы

## Цели лекции

- Определить критерии третичного перитонита и отличить его от вторичного.
- Сформулировать алгоритм диагностики и лечения третичного перитонита.
- Обосновать роль open abdomen и planned re-laparotomy в управлении абдоминальным сепсисом.
- Определить принципы мультидисциплинарного ведения пациента с абдоминальным сепсисом в ОРИТ.
- Сформулировать критерии «невозможности source control» и перехода к паллиативной тактике.

## Введение. Когда хирургия проигрывает

Третичный перитонит — самое тяжёлое состояние в абдоминальной хирургии: source control выполнен, АБТ адекватна, дренировано — но инфекция не отступает или возвращается. Летальность 40–60 %, в некоторых сериях до 70 %. Пациент в состоянии иммунологического истощения, когда организм не способен элиминировать инфекцию даже при адекватной хирургии. Это хирургически-реанимационная проблема, решаемая только командой.

## 1. Определение и критерии

**Определение (WSES 2024):** персистирующая или рецидивирующая интраабдоминальная инфекция, сохраняющаяся несмотря на адекватный первичный source control и АБТ.

**Критерии диагноза:** первичный source control выполнен адекватно; АБТ назначена (эмпирическая → целенаправленная); персистенция инфекции > 48 ч (лихорадка, лейкоцитоз, ↑ CRP/PCT, перитонеальные знаки сохраняются/рецидивируют); положительные посевы из брюшной полости после 48 ч АБТ; исключён альтернативный источник (пневмония, катетер-ассоциированная инфекция, раневая инфекция).

| Параметр | Вторичный | Третичный |
|---|---|---|
| Source control | Не выполнен/неадекватный | Выполнен, адекватный |
| Микробиология | «Классическая» | Резистентные штаммы, грибы |
| Ответ на АБТ | Обычно положительный | Отрицательный/неполный |
| Прогноз | Летальность 10–30 % | Летальность 40–60 % |

## 2. Микробиология третичного перитонита

| Возбудитель | Частота |
|---|---|
| ESBL E. coli/Klebsiella | 25–35 % |
| Pseudomonas aeruginosa | 15–25 % |
| Enterococcus faecium (VRE) | 15–20 % |
| Candida spp. (в т.ч. C. auris) | 15–25 % |
| MRSA | 5–10 % |
| CRE (KPC, NDM, OXA-48) | 5–15 % |
| Стерильные посевы | 20–30 % |

Посевы обязательны при каждом re-look: аэробы + анаэробы + грибы; молекулярная диагностика (PCR карбапенемаз, 16S rRNA при отрицательных посевах); повторно каждые 48–72 ч.

## 3. Алгоритм лечения

**Шаг 1. Верификация адекватности source control** — re-look (лапароскопия/лапаротомия): нераспознанный источник? Несостоятельность анастомоза/культи? Недедренированный абсцесс? КТ с в/в контрастом. Если source control неадекватный — это недиагностированный вторичный перитонит, не третичный.

**Шаг 2. Коррекция АБТ** по посевам: при CRE — цефтазидим/авибактам, цефидерокол, high-dose meropenem + комбинация; при VRE — линезолид, даптомицин; при Candida — эхинокандины.

**Шаг 3. Поддержка в ОРИТ:** гемодинамика (GDFT, вазопрессоры), респираторная поддержка (lung-protective ИВЛ, prone при ARDS), раннее энтеральное питание (24–48 ч, белок 1,2–2 г/кг/сут), гликемический контроль (140–180 мг/дл), коррекция коагулопатии по TEG/ROTEM, CRRT при AKI.

**Шаг 4. Open abdomen и planned re-laparotomy:** невозможность закрытия, потребность в повторных re-look каждые 48–72 ч, дренирование персистирующей контаминации; критерии прекращения re-look — чистая брюшная полость, отсутствие контаминации, грануляции.

**Шаг 5. Мультидисциплинарный консилиум:** хирург (source control, re-look), реаниматолог (гемодинамика, ИВЛ, нутриция), микробиолог (посевы, резистентность), клинический фармаколог (коррекция АБТ), нутрициолог.

## 4. Критерии «невозможности source control» и паллиативная тактика

Source control невозможен при: тотальном некрозе кишечника (> 80 % тонкой), некорригируемом ДВС, рефрактерном шоке (норадреналин > 2 мкг/кг/мин), неоперабельной онкологической патологии с перфорацией и карциноматозом, мультиорганной недостаточности (SOFA > 12) с необратимым прогнозом.

**Переход к паллиативной тактике** принимается консилиумом (хирург + реаниматолог + паллиативная служба/этический комитет): информирование семьи, обсуждение целей лечения (cure vs. comfort), аналгезия/седация/комфорт, документирование решения. Это не «сдаться» — это признание границ медицины.

## 5. Прогностические факторы

| Фактор | Влияние |
|---|---|
| MPI > 29 | Летальность > 50 % |
| SOFA > 12 | Летальность > 80 % |
| Лактат > 6, не снижающийся за 24 ч | Летальность > 70 % |
| CRE/C. auris в посевах | Летальность > 60 % |
| Возраст > 75 + Charlson > 5 | Летальность > 60 % |
| Третичный перитонит (vs. вторичный) | OR летальности 3,5 |

## Клинический кейс

Мужчина, 68 лет. 12 дней назад — резекция сигмы (Hartmann) по поводу перфоративного дивертикулита. АБТ меропенем 10 дней. На 12-е сутки — лихорадка 39,6 °C, АД 90/55 (норадреналин), WBC 24, CRP 380, PCT 22, лактат 5,2, тромбоциты 55, INR 1,9. КТ: множественные межпетлевые абсцессы, свободная жидкость, пневмоперитонеум. Посевы: Pseudomonas aeruginosa (MDR) + Candida glabrata + Enterococcus faecium (VRE).

**Диагноз:** третичный перитонит, healthcare-associated, severe, септический шок, полиорганная недостаточность (SOFA 11).

**Тактика:** re-laparotomy (лаваж, дренирование абсцессов, оценка культи, open abdomen NPWT); АБТ цефтазидим/авибактам + микафунгин + линезолид; ОРИТ (ИВЛ, вазопрессоры, CRRT, энтеральное питание); re-look каждые 48–72 ч; ежедневный консилиум. Динамика: лактат 5,2→1,8 (день 6), отключение вазопрессоров, чистая брюшная полость (день 10), закрытие open abdomen (день 12), выписка из ОРИТ (день 21).

## Заключение. Семь принципов

1. Третичный перитонит — диагноз исключения: сначала убедитесь, что source control был адекватным.
2. Микробиология смещена: резистентные штаммы, грибы — посевы при каждом re-look.
3. АБТ целенаправленная, не «максимально широкая»: stewardship.
4. Open abdomen — не поражение, а стратегия: NPWT + planned re-look каждые 48–72 ч.
5. Мультидисциплинарность обязательна: еженедельный (или чаще) консилиум.
6. Прогноз оценивайте динамически: лактат-клиренс, PCT-kinetics, SOFA.
7. Знайте границы: когда source control невозможен — паллиативная тактика.
